## Platform

web

## Product Purpose

sametbrr.com is Samet Birer's existing bilingual portfolio. Preserve its pages and content. The user requested a separate focus companion named **Pato**, based on the functional scope of Pofi, with an original potato character.

## Users

People working at a computer who want focus sessions and reminders to take walking or seated movement breaks.

## Capabilities and Constraints

Configurable focus sessions and breaks, character journey, local persistence, daily statistics, sounds, compact window, phone pairing and opt-in notifications. Background mobile reminders require server scheduling, persistent storage and Web Push configuration. No deployment, commit or push is authorized by this request.

## Brand Commitments

The user confirmed the Turkish name Pato. Keep the existing portfolio. Use original character artwork and copy rather than copying Pofi's assets or implementation. The tool is a separate page at /pato, with the existing English locale supported. Pato follows the main site’s existing light/dark theme and saved preference. Keep the main timer compact and settings accessible in a tabbed modal to reduce scrolling.

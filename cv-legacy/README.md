# Eski CV (arşiv)

> **⚠️ Önemli:** Bu klasör artık kullanılmıyor; yalnızca arşiv için duruyor.

Güncel CV sitedeki `/cv` sayfasıdır (İngilizce: `/en/cv`). İçeriği `content/*.yaml` dosyalarından gelir, PDF'i `pnpm cv:pdf` ile `public/cv/` altına üretilir.

Buradaki `index.html` eski `cv.sametbrr.com` sürümüdür; görsel tabanlı PDF ürettiği ve içeriği ayrı tutulduğu için yerini yeni CV aldı.
